# E06-S02 List the bin

- **Epic:** E06 Recycle bin
- **Status:** Draft
- **Depends on:** E06-S01
- **Decisions:** D-035
- **Flows:** FLOWS.md 7.1

## Goal

A user can see what is in the bin.

## Scope

- Endpoint listing bin items with name, alter, original location and deletion date.
- A deleted folder shows as one item.

## Acceptance criteria

- Every deleted item is listed until restored or permanently deleted.
- Items inside a deleted folder are not listed separately.
