# E08-S04 Thumbnail grid view

- **Epic:** E08 Explorer UI
- **Status:** Draft
- **Depends on:** E08-S02, E08-S03
- **Decisions:** D-011
- **Flows:** FLOWS.md 3.2, 10

## Goal

A user can switch from the table to a grid of tiles.

## Scope

- Toggle between details list and grid; the browser remembers the choice.
- Tiles show a thumbnail or type icon, the name and the alter.
- Selection and right-click behave as in the list.

## Acceptance criteria

- Both name and alter are visible on every tile.
- Only visible tiles request thumbnails.
