# E08-S09 Keyboard shortcuts

- **Epic:** E08 Explorer UI
- **Status:** Draft
- **Depends on:** E08-S07, E08-S08
- **Decisions:** D-011, D-043
- **Flows:** None

## Goal

The app can be driven from the keyboard like Explorer.

## Scope

- F2 rename, Delete, Ctrl+A, arrow keys, Enter to open, Backspace or Alt+Up to go up.
- Sensible focus movement between tree, list and dialogs.
- A shortcuts list the user can open.
- Shortcuts are a desktop extra: nothing is reachable only through them.

## Acceptance criteria

- Every listed shortcut works in both list and grid.
- A user can upload, rename and delete without the mouse.

## Open questions

- Which shortcut edits the alter? (proposed: Shift+F2)
- Which shortcut opens Go-to? (proposed: Ctrl+G)
