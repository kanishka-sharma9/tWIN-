## Goal

The window is laid out like a file explorer and remembers where the user is.

## Scope

- Folder tree pane, breadcrumb bar, toolbar, content area and status bar.
- Back, forward and up.
- The address reflects the current folder, so links and refresh work.
- Resizable tree pane.
- The product name tWIN!! in the header and the page title.

## Acceptance criteria

- Opening a copied link lands in the same folder.
- Back and forward retrace the folders visited.
