# E08-S05 Right-click menu and toolbar actions

- **Epic:** E08 Explorer UI
- **Status:** Draft
- **Depends on:** E08-S02
- **Decisions:** D-011, D-017, D-043
- **Flows:** None

## Goal

Every action is reachable from a right-click and from the toolbar.

## Scope

- Menus for a file, a folder, empty space and a multi-selection.
- Actions: open, download, rename, change alter, move, copy, delete, new folder, upload.
- The toolbar mirrors the menu for the current selection.
- A long-press opens the same menu on touch screens.

## Acceptance criteria

- Each menu shows only the actions valid for what was clicked.
- Every action works from both the menu and the toolbar.
