# E08-S08 Selection and bulk actions

- **Epic:** E08 Explorer UI
- **Status:** Draft
- **Depends on:** E08-S02, E05-S06, E05-S08, E06-S01
- **Decisions:** D-011
- **Flows:** None

## Goal

A user can select many items and act on them together.

## Scope

- Click, Ctrl-click, Shift-click and select all.
- Bulk move, delete and download.
- Selection count in the status bar.

## Acceptance criteria

- Shift-click selects the range between two items.
- A bulk action applies to exactly the selected items.
